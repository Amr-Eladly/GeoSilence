## GeoSilence: Location-Based Sound Profile Management

This project aims to design and implement a mobile application that manages a phone's sound profile based on the user's geographic location. The application allows users to define places, such as universities, libraries, and workplaces, and associate them with a preferred sound mode and a geographic boundary. When the user enters a configured area, the application applies the selected mode automatically or requests confirmation, and restores the previous settings after leaving the active areas. An interactive map and a dedicated places list provide tools for finding locations and managing these rules. The system combines local data storage with user authentication and cloud synchronization, allowing users to retain their saved places across sessions and devices. It also distinguishes between private and publicly shared places. The application is intended to reduce the need for manual sound adjustments while allowing users to control how their device responds to different environments. Its functionality and responsiveness should be evaluated, while location accuracy, background execution restrictions, permissions, and user privacy should also be considered.

## Tasks to be performed by the student

- Analyze the requirements and platform constraints for location-based sound profile management.
- Design and implement the application architecture and database for saved places and their associated settings.
- Develop geofencing functionality for automatic and confirmation-based sound mode changes and restoration of previous settings.
- Create an interactive map and user interface for searching, adding, editing, and managing private and publicly shared places.
- Integrate user authentication, account management, and synchronization between local storage and the cloud.
- Test the application and evaluate its responsiveness and reliability, discussing location accuracy, privacy, and platform limitations.
